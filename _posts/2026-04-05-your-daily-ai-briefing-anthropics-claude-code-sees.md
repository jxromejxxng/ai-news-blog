## Anthropic's Claude Code: Integrations to Cost More

If you're a developer or part of a team using Anthropic's Claude Code for your coding tasks, especially with third-party tools like OpenClaw, get ready for a change. Anthropic has announced that subscribers will soon need to pay extra to use Claude Code with these external integrations.

**What does this mean for you?** Essentially, the convenience of having Claude Code seamlessly integrated with your preferred dev tools (like OpenClaw, which is a big one for many) will no longer be part of the standard subscription. This move could impact your budget if you've built your workflow around these combined capabilities. It's a reminder that as these AI tools mature, companies are looking for sustainable business models, and sometimes that means unbundling features that were once included.
